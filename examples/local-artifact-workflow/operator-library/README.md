# Operator artifact starter

A standalone first-party source catalog for creating a fresh Evidence Steward.
It contains one preset, one expression and the nine required module kinds. No
compiled identity, live agent, provider credential or skill body is included.

Seven unchanged module definitions come from the repository's first-party
`fixtures/creation/modules` catalog. The `godskills` and `embodiment` modules
are derived, renamed definitions that remove generic filesystem claims. Their
provenance is retained. The expression and preset derive from Quiet Cartographer.
This independence from fixture paths is packaging, not proof of superior quality.

The Realm permits only publication and verification of accepted local artifacts.
It does not provide arbitrary filesystem tools, automatic deletion, hostile-user
isolation or cloud durability. The host must still grant the required authority.

Numeric attributes and personality dimensions describe intended design, not
measured IQ, consciousness or guaranteed behavior. Evolution remains frozen and
Soul remains dormant. The initial cortex declares OpenAI-compatible operation;
Grok and Anthropic mappings require separate explicit profiles and qualification.
Godskills eligibility does not activate a skill or grant any authority. The host
pins its release separately and selects a bounded mission stack when applicable.

Review the policy and preset through the public creator CLI, finalize with the
reviewed preview digest, and freshly prepare workflow protocol 3. See
`docs/local-artifact-workflow.md` in the repository for operator steps. This
starter does not silently upgrade an existing agent or authorize provider cost.
