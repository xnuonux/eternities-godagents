## Decision

Add one coherent third character path instead of scattering cosmetic options or inventing unsupported operational infrastructure.

**Ilyra, the Luminous Emissary** combines:

- `lineage:synthetic-empath@1.0.0`;
- `archetype:diplomatic-orchestrator@1.0.0`;
- `attributes:social-balanced@1.0.0`;
- `personality:warm-diplomat@1.0.0`;
- `voice:resonant-warm@1.0.0`;
- `expression:ilyra-emissary@1.0.0`;
- the already proven builder organs, portable Godskills router, replaceable cortex contract, and local workbench embodiment.

This grows the identity-bearing categories from two choices to three while leaving organs, Godskills, cortex, and embodiment singular until a genuinely implemented alternate runtime exists. The new archetype provides the existing systems-architect compatibility tag so the shared operational core remains valid, but it also requires the new lineage and owns a distinct diplomatic-orchestrator tag for its attribute contract.

The new preset remains pre-genesis, uses the existing frozen constitution and Prompt OS constraints, and grants no new effect, capability, adapter, Realm authority, evolution, Inspiration, or Soul state.
