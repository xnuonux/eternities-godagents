# Local Admission Shell v1 Certification

## Boundary

This append-only certificate proves the trusted-local-workspace admission shell as a deterministic composition of already certified creation, foundry, and transactional-genesis boundaries. It certifies pre-write source validation, immutable snapshot binding, exact Realm capability matching, workspace ownership and observed reparse refusal, interrupted publication recovery, transactional-genesis recovery, closed CLI output, inert local admission, and preservation of every earlier receipt.

It does not claim OS-level isolation from a hostile process concurrently manipulating paths under the same Windows user. It does not certify or perform vessel start, model calls, host authority, Realm actions, governed evolution, Inspiration, Lunari integration, hosted persistence, multi-user operation, or Soul activation.

## Requirements

- `GLA-001`: creation pins, snapshots, Prompt OS, Realm contract, and distribution verify before workspace writes.
- `GLA-002`: supplied Realm capabilities equal the verified genome requirement set.
- `GLA-003`: one canonical binding owns exact immutable creation and distribution snapshots beneath one dedicated workspace.
- `GLA-004`: changed creation, Prompt OS, Realm, instance, creator, or checkpoint input cannot reuse an occupied admission.
- `GLA-005`: pre-existing and observed junctions, symbolic links, and unexpected workspace entries fail closed within the trusted-local boundary.
- `GLA-006`: every shell publication and transactional-genesis interruption resumes to one exact journal and keel admission.
- `GLA-007`: the CLI accepts only nine closed arguments and emits one bounded canonical result or a code-only failure.
- `GLA-008`: admission adds no runtime, provider, host, Realm-action, evolution, Inspiration, Lunari, or Soul activation surface.
- `GLA-009`: all six preceding certification receipts retain exact bytes and SHA-256 digests.

## Reproducibility

The certifier runs the complete no-network suite, performs two isolated fixed-clock admissions from independently compiled creation fixtures and snapshotted Prompt OS and Realm inputs, and compares the bounded result plus every workspace byte. The receipt binds the exact source commit, specification and plan, source and test manifests, deterministic test projection, admission fixture digest, creation/distribution/genesis/keel identities, exclusions, and historical receipt digests.
