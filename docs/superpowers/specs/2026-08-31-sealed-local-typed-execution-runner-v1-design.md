# Sealed local typed execution runner v1

## Objective

Compose the exact local Godskills routing and activation executables, recoverable typed-composition intent, certified typed execution stepper, and recoverable per-node journal behind one explicit programmatic factory.

## Construction boundary

The caller supplies release pins, one activation classifier, mission data, and node executors. The factory verifies and privately constructs every transport, adapter, registry, compiler, and journal. It accepts no route transport, activation transport, activation result, typed method, registry, or execution handle from the caller.

## Execution

1. The historical recoverable compiler validates and durably binds the complete topology before external work.
2. The sealed local process transports route and activate the mission with content-addressed process recovery.
3. The compiler persists the body-free compilation identity.
4. The runner rehydrates the exact durable binding, reconstructs the same unsigned plan, recompiles through the verified stepper adapter, and requires plan and method digest parity with the compiler record.
5. The certified typed execution journal validates, publishes, replays, and resumes node outputs.

## Recovery

The same request after process death reconstructs local route and activation completion, recompiles the exact method, replays durable node outputs through fresh private Godskills steps, and invokes only the first unfinished node. Changed topology or binding input collides with the durable compiler intent. Changed mission inputs produce a different journal identity and cannot rehydrate the earlier execution.

## Limits

The classifier and node executors remain trusted. Local process recovery prevents repeated completed route and activation work, while node execution remains at-least-once across the interval between executor return and durable output publication. The runner is additive and not a default host, vessel, CLI, or launcher path. It grants no provider credential, Realm, continuity, keel, evolution, Lunari, Inspiration, or Soul authority.
