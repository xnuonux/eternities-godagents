# Sealed local typed-composition compiler v1 implementation plan

1. freeze canonical Godagents main and all existing Godskills and typed compiler
   receipt coordinates.
2. write failing tests for one caller-transport-free sealed factory and its
   closed provenance-branded surface.
3. extract a shared verified local process transport bundle without changing
   the existing local recoverable Godskills adapter behavior.
4. construct the recoverable typed compiler internally from that exact route
   and activation transport pair.
5. write a real-process Muse-to-Forge test that proves one route child and one
   activation child launch.
6. interrupt after activation result and success publication, reconstruct, and
   prove no child relaunch or caller replay is required.
7. retain typed execution, topology-before-route rejection, pin drift, forged
   wrapper, and cross-factory ownership regressions.
8. build one deterministic fixture and append-only certification receipt with
   exact source, implementation, test, historical receipt, and executable roots.
9. run focused, complete, ledger, lineage, and deterministic replay gates.
10. fast-forward canonical main, push, and remove only the clean verified
    feature worktree.

## stop conditions

- the caller can inject either local process transport;
- the caller can supply an activation result or typed method;
- recovery relaunches a completed route or activation child;
- the existing local adapter behavior regresses;
- any default host path changes;
- authority or identity boundaries expand;
- an unresolved critical or important defect remains.
