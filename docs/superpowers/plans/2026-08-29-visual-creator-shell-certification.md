# Visual Creator Shell v1 Certification Plan

## Goal

Issue one immutable, reproducible certificate for the local modular visual creator without changing the certified Phase 3 protocol or any historical receipt.

## Tasks

1. Add failing request-boundary tests for the complete token-gated route matrix, cross-kind and unavailable composition selections, blocked composition acknowledgement and finalization, composition-route canary non-reflection, and composition publication through the existing confinement defenses.
2. Implement only the smallest production corrections exposed by those tests. Preserve the existing creator protocol and finalization path.
3. Add a fail-closed `visual-creator-shell-v1` receipt builder and certifier with `GVC-001` through `GVC-009`, fixed exclusions, historical receipt pins, clean-source checks, guarded-suite projection, and two isolated pure-handler fixture runs.
4. Add receipt-builder and certifier tests, the package script, architecture and operator documentation, then generate the source receipt only from a clean pinned commit.
5. Run the full no-network suite, reproduce all historical builds and receipt hashes, request independent P0/P1/P2 review, reconcile upstream, fast-forward main, rerun merged gates, push, verify parity, and clean the owned worktree.

## Acceptance

- every `GVC-*` row and proof gate is fail-closed;
- both isolated web-handler runs produce the certified Aether build and identical byte manifests;
- the source receipt pins the exact clean source commit and excludes product claims outside the local deterministic boundary;
- all historical build IDs and receipt hashes remain unchanged;
- main and origin/main are equal after merged verification.
