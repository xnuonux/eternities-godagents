# Godskills typed-composition consumer v1 implementation plan

1. freeze Godagents main and the exact pushed Godskills typed-composition v1
   commit, receipt bytes, module, policy, parent roots, and canary digests.
2. add one closed static pin and schema. do not modify the existing Godskills
   release pin, router, adaptive adapter, mission vessel, or launch paths.
3. write failing tests for exact release verification, private provenance,
   canonical paths, file containment, receipt identity, source closure, every
   declared and generated artifact, parent roots, and canary digest closure.
4. implement the release verifier with exact regular-file reads, bounded byte
   counts, duplicate-path rejection, canonical receipt verification, and a
   module-private verification brand.
5. write failing adapter tests for verify-before-import, exact exports, registry
   reconstruction, deterministic plan compilation, body-free metadata, and
   exact Muse-to-Forge execution.
6. implement the optional in-process adapter without routing, activation,
   persistence, retry, provider, credential, Realm, continuity, or default
   launch behavior.
7. add adversarial tests for pin drift, changed receipt/module/policy/schema/
   source/generated bytes, path aliases, forged verification, changed plan,
   changed activation, foreign method identity, missing executor, malformed
   input, and malformed output.
8. generate the actual cross-repository canary fixture against the pinned
   Godskills root and require the published method and execution digests.
9. run focused compatibility tests, inline adversarial review, and the full
   Godagents suite. repair any confirmed ambient-state regression at its
   declared trust boundary. issue one append-only certification receipt from
   the exact feature source commit.
10. update the certification ledger and release lineage for one new receipt,
    merge by fast-forward, push canonical main, and remove only the verified
    clean feature worktree.

## stop conditions

- any byte in the Godskills typed-composition release differs from the pin;
- the adapter must infer a plan field, activation decision, effect, or
  authority;
- composition requires method or reviewer body preloading;
- existing Godagents default behavior or historical receipt bytes change;
- any generated fixture or receipt fails exact reconstruction;
- any unresolved critical or important defect remains.
