## Boundary

An issued workspace owner authenticates a fresh `local-workspace-v3` admission and an externally pinned host policy. It uses the existing issued effect-only launcher for a proposed replacement, not execution authority. The exact source/preimage and parent revision travel in the bounded mission objective. Accepted completion is authenticated before deriving a child in the existing revision store. Source files and previous revisions are never promoted or modified.

Independent host review owns whether exact child bytes may run under the existing reviewed-local-browser profile. Review, suite and runtime bindings must be immutable and separate from model output. No result-shaped object or self-hashed receipt is authority. Existing native reconciliation is reused; browser dispatch records must distinguish prepared, dispatched, completed and uncertainty. This is a bounded side-effect record, not a second generic scheduler or provider journal.
