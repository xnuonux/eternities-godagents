## inline adversarial review

no independent reviewer was used because the user required inline execution
without subagents. the inline review found and repaired two material defects,
and both attacks remain permanent regression tests:

1. a selected route could falsely carry a terminal-only `no-selection` or
   `unresolved-decision` reason;
2. a re-signed preference release receipt could omit part of its declared
   dependency closure because the verifier required only a bounded subset.

after repair, the verifier requires the exact closure, source, routing, and
output path sets, and both initial binding and recovery reject contradictory
terminal reasons. no unresolved critical defect was found in the certified
surface.
