## certified boundary

One canonical JSON policy fixes an HTTPS origin, query-free endpoint, model,
credential variable name, timeout, request and response byte ceilings, and
independent phase token and completion ceilings. Its SHA-256 must match the
external `GODAGENT_PHASE_TRANSPORT_POLICY_SHA256` pin before descriptors,
credentials, durable operations, or network requests are created.

The model sees one stable phase instruction and one canonical untrusted data
package. It returns strict JSON only. Trusted code assigns artifact type,
identity, authority, subject, input, usage, timestamp, and completion-digest
fields, then passes the result through the already certified phase contracts.

The credential is resolved lazily after local preflight. Its value reaches
only the in-memory Authorization header. It is excluded from policy,
descriptors, request bodies, durable state, results, errors, fixtures, and
receipts. Credential-bearing input or reflected output fails closed.

## execution and recovery proof

The deterministic fixture executes one admitted consequential visual mission
through the real routing executable and activation classifier. The selected
path is:

`native -> review -> revision -> review`

Four provider calls produce four durable phase completions and a final
`revision-review-accepted` verdict. Exact terminal replay returns the same
closed host result with zero provider, routing, or activation calls. The
complete fixture root contains zero copies of the credential canary and the
mission expands neither Realm nor authority.

Every operation publishes an immutable prepared record and a durable attempt
record before HTTPS. A verified completion replays locally. Process death or
an ambiguous network failure after attempt publication remains pending and is
never automatically retried. This proves local at-most-once dispatch, not
universal remote exactly-once execution.
