## Evidence scope

Actual installed Pi coding-agent/AI runtime: **0.85.1**, Windows, Node >=24.
The provider is scripted, but the Pi session manager, inference loop, native
read/write/PowerShell tools, saved transcript and adapter are real. No production
repository was handed to the fixture's native tools. Fixture workspaces are
temporary copies of the existing export-inspector example.

`tests/native-host-binding.test.mjs` verifies host-pinned authority, native
session/model identity, effect ceilings, action argument/result binding,
credential-free hash records, revocation, expiry, duplicate calls, tool budget,
clean resume, missing/corrupt state, mismatched results and unresolved actions.
Corrupted evidence is preserved during settlement/closure, not silently repaired.

`tests/pi-native-session.test.mjs` verifies:

- A real native write, closure and same-actor/same-session continuation.
- Native retrieval beyond the obsolete 4,096-character mission/source ceiling.
- Real native PowerShell execution only with explicit process authority.
- Expiry between model response and tool dispatch prevents a real file write.
- Expiry after a completed tool blocks the next provider invocation while
  preserving evidence of the already completed effect.
- A revoked binding never reaches the provider.
- Transcript changes fail on resume and remain rejected across repeated prompts.
- Provider failure is reported as failure, not product completion.
- A throwing provider stream retains provider-failure semantics; an explicit
  later prompt can recover without reopening or changing authority.
- Actual automatic compaction is counted separately from native inference.
  Summary failure returns a warning and permits a later successful continuation.
- Native same-prompt retry success is not mislabeled by an earlier failed
  attempt. Exhausted retries fail without revoking subsequent operator work.
- Ordinary unbound Pi is unaffected; importing the optional public entrypoint
  does not load the Pi runtime or discover credentials.

Initial regression demonstrations failed before implementing the relevant paths:
unauthorized shell grant, absent SDK adapter, corrupt-evidence overwrite, and
unbound transcript adoption. The final targeted command and full-suite result
are recorded in the completion section below.

## Remaining product gates

This is a usable programmatic host integration, not a polished launcher or a
claim of coding-quality superiority. Next: live Grok subscription qualification
inside Pi, then a thin operator launch/adoption experience around this same SDK
path. Do not build a second inference/tool loop.

Large-session compaction stress, provider-specific cancellation, governed model/host
migration, externally qualified Godskills activation, hard native billing
ceilings and broader usability remain separate work. There is no OS-level
isolation against the same user/host, no automatic rollback or replay of an
uncertain shell effect, and no Soul, Inspiration or Lunari activation.
